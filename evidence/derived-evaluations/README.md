# Derived paired-evaluation receipts

This directory contains 104 first-party local paired-evaluation receipts from
the Maze Crawler research workspace. Each CSV is a compact outcome table with
the seed, the two candidate labels, rewards, status, winner, and step count.
They document experiments run by this project; they are not server replay
downloads, submission packages, input files, or copied kernels.

The filenames describe the candidate comparison and seed protocol. Opponent
labels are retained as research provenance, not as a redistribution of another
participant's code. The records do not contain board states, action streams,
competition inputs, or generated submissions.

Use the scripts in this repository with an authorized competition environment
to reproduce a new evaluation. Historical receipts describe local evidence and
do not claim a current leaderboard position.
