# Publication boundary

This repository publishes first-party source (including reviewed submission
scripts) and the research evidence produced by running it. It does not publish
the original Maze Crawler competition data, server-downloaded or opponent
replays, or third-party kernel copies.

Reviewed, user-authored generated artifacts—such as compiled submission bundles
and local simulation records—may be released separately when their manifest
names the producing source revision, origin boundary, licence context, exact
file size and SHA-256. Large artifacts belong in a public Kaggle Dataset or a
release attachment, not ordinary Git history. A bundle that contains upstream
or organizer-owned bytes must identify them and must not be relicensed as a
wholly original work.

The `evidence/derived-evaluations/` CSVs are included because they are local
paired-evaluation outcomes: metrics and candidate labels generated by this
project. They contain no replay state/action sequence or organizer-provided
record. An inference someone might draw from a documented experiment is not a
reason to discard the experiment; redistributing a source file or a material
explicitly restricted by its owner is.

When an artifact cannot be included, repository documentation should name the
official source and state what a reader needs to obtain it lawfully.

For the competition description, rules, evaluation details, inputs, and public
replay access, use the official [Maze Crawler competition page](https://www.kaggle.com/competitions/maze-crawler)
rather than a copied page snapshot in this repository.
